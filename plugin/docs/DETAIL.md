# 截图提问助手接口

这个插件给「截图提问助手」桌面浮窗提供本地模型接口。它本身没有界面，装上之后在你的 DSH 本地 Web 服务上挂两个地址：

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| `GET` | `/shot-ask/ping` | 健康检查，返回当前默认模型 |
| `POST` | `/shot-ask/ask` | 传入截图与问题，以 SSE 流式返回答案 |

## 请求格式

```json
{
  "image": "data:image/jpeg;base64,...",
  "mediaType": "image/jpeg",
  "question": "这页 PPT 在讲什么？",
  "history": [{ "q": "上一轮的问题", "a": "上一轮的回答" }]
}
```

## 说明

- 模型、账号和额度都复用 DSH 当前配置，不需要额外填写 API Key。
- 截图会交给 DSH 的附件服务做格式校验与尺寸归一化，再作为图片消息发给模型。
- 回答通过 SSE 的 `delta` 事件逐段返回，最后以 `done` 事件结束；出错时返回 `error` 事件。
- 这个接口只监听本机回环地址，不对外网开放；截图不会离开这台电脑。
